# CBC Long Range Visuals

Аддон для **Minecraft 1.21.1 / NeoForge** к **Create Big Cannons**.
Реализован экспериментальный профиль **«Читаемо вдали»**, версия **0.1.2-dev**.

## Возможности

- Состояние снарядов передаётся сервером раз в 2 тика, по умолчанию до 4096 блоков.
- Клиент рисует отдельные визуальные объекты без поддельных боевых сущностей.
- Учитываются настоящий флаг трассера и режим следа CBC `NONE / SHORT / LONG`.
- Трассеры имеют короткий светящийся след и ограниченную минимальную толщину на экране.
- Дым использует те же `minecraft:big_smoke_0…11`, что и CBC. Небесный и блочный свет
  передаются сервером, а текущая световая карта клиента учитывает ночь и смену времени суток.
- Для дыма и событий действуют общие бюджеты. Уже оставленный дым доживает после удаления снаряда.
- При появлении настоящей сущности CBC её дальний рендер и генерация дальнего дыма подавляются.
- Синхронизируются дымовые завесы, включая изменения положения и размеров при слиянии.
- Поддержаны попадания, рикошеты, HE, flak, шрапнель/картечь, камень и жидкостные разрывы.
  Цвет жидкости берётся из её клиентского типа. Разлёт осколков визуально приближённый.

Баллистикой, взрывателями, уроном и загрузкой серверных чанков управляют CBC/RPL.
Дульные эффекты и дальний звук в эту версию не входят.

## Установка и настройка

Установи одинаковый JAR **на сервер и на клиент**, вместе с Create, CBC и RPL.
В одиночной игре серверная часть запускается автоматически. Сетевой канал необязателен:
клиенты без аддона могут подключаться к серверу с аддоном, пакеты им не отправляются.
В 0.1.1 изменён формат пакетов для передачи света; клиент и сервер нужно обновить вместе.

- Клиент: `config/cbc_long_range_visuals-client.toml` — дым, толщина/длина трассеров,
  бюджеты и адаптер Roxy.
- Сервер: `<мир>/serverconfig/cbc_long_range_visuals-server.toml` — дальность,
  интервал кадров и лимиты объектов/событий для каждого игрока.
- `/cbcvisuals status` — число кадров и объектов, состояние адаптера Roxy.
- `/cbcvisuals preview 2048` — локальная демонстрация в направлении взгляда на 20 секунд,
  без игровых сущностей и урона. Доступно 256–4096 блоков. На время демонстрации обычные
  визуальные кадры игнорируются, затем рабочий режим восстанавливается.

## Совместимость

- **Roxy + Voxy:** свой шейдер обходит обычную дальнюю плоскость и короткий туман.
  Необязательный адаптер читает текущую LOD depth/stencil frame из `RoxyLodEntityOcclusion`
  с учётом reverse-Z и диапазона Z. При несовместимом изменении внутреннего интерфейса Roxy
  адаптер отключается с сообщением в журнале; обычная проверка глубины Minecraft остаётся.
  Полный прогон с конкретной сборкой Roxy/Voxy и шейдерпаком пока не выполнен.
- **Sable / Aeronautics:** мировые координаты и направления получаются через
  `CBCCompatTransformers`; скорость корабля повторно не добавляется, физика не меняется.
  Нужна совместимая с этими модами версия CBC. Полный игровой прогон с кораблями пока не выполнен.
- Эти моды необязательны. Обычные клиентские чанки для создания дальних эффектов не требуются.

Источник контракта Roxy:
[RoxyLodEntityOcclusion](https://github.com/RasaNovum/Roxy/blob/main/versions/1.21.1/src/main/java/net/rasanovum/roxy/compat/RoxyLodEntityOcclusion.java).

## Подготовка и сборка (CMD)

Нужны установленный Python 3 и интернет для первой загрузки. В корне проекта:

```bat
setup-dev.cmd
```

Скрипт устанавливает переносимый JDK в `.tools/java21`, проверяет SHA-256 JDK и Gradle Wrapper,
собирает аддон и готовит конфигурации клиента и сервера. Системные `JAVA_HOME` и `PATH` не изменяются.
Кэш Gradle хранится в `.gradle-user-home` внутри проекта. Первая подготовка скачивает Minecraft,
NeoForge и библиотеки и может занять значительное время.

После подготовки:

```bat
dev.cmd build
dev.cmd runClient
dev.cmd runServer
```

`runClient` запускает тестовый Minecraft с Create, CBC, RPL и аддоном. Каталог клиента — `run`.
Сервер использует `run-server`; для его запуска нужно самостоятельно принять Minecraft EULA
в `run-server/eula.txt`. Скрипты не принимают EULA за пользователя.

Готовый мод: `build/libs/cbc-long-range-visuals-0.1.2-dev.jar`.
Архив `-sources.jar` содержит исходники и не устанавливается в игру.
Зависимости устанавливаются отдельно: они не упаковываются в JAR аддона.

## IDE

Открой корень проекта как Gradle-проект в IntelliJ IDEA. В **Settings → Build Tools → Gradle**
выбери **Gradle JVM** = `<проект>/.tools/java21`, **Gradle user home** = `<проект>/.gradle-user-home`.
Project SDK / language level — Java 21. После импорта ModDevGradle создаёт конфигурации запуска.
Для VS Code добавлены настройки JDK/Gradle и рекомендуемые Java-расширения.

При запуске через обычный `gradlew.bat` нужно самостоятельно указать существующий JDK 21 в `JAVA_HOME`.
`dev.cmd` делает это автоматически в пределах своего процесса.

## Проверка и структура

```bat
dev.cmd test build
```

Тесты проверяют протокол, большие координаты, ограничения списков, нечисловые значения,
интерполяцию, ограничение экстраполяции, разрывы траектории, бюджеты частиц и упаковку света.
Базовый клиент с Create/CBC/RPL загружался и подключался к одиночному миру.
В 0.1.2 исправлено падение при создании первого дальнего дымового следа: атлас частиц
получается из `TextureManager`, где его регистрирует `ParticleEngine`. Менеджер моделей
не содержит атлас частиц. При временной недоступности атласа используется процедурный дым.

Отдельный графический регрессионный тест запускается на копии мира `run/saves/test`:

```bat
python scripts\prepare_smoke_test.py
dev.cmd runClient -PclientSmokeTest
```

Он рисует дальний дым днём и ночью, проверяет 12 спрайтов, ошибки OpenGL и перезагрузку ресурсов,
затем закрывает свой клиент. Результат: `.tools/smoke-test-run/smoke-result.txt`.
Прогон 0.1.2 на базовой связке NeoForge/Create/CBC/RPL завершился успешно:
505 кадров с дымом, день/ночь и перезагрузка ресурсов, без ошибок OpenGL.
Исходный мир остаётся неизменным. Тестовый мод из `src/clientSmokeTest` не попадает в JAR аддона
и не загружается при обычном `dev.cmd runClient`.

- `src/main/java/dev/likip/cbclongrangevisuals/CbcLongRangeVisuals.java` — общая точка входа.
- `src/main/java/dev/likip/cbclongrangevisuals/client/` — состояние, интерполяция, рендер и адаптер Roxy.
- `src/main/java/dev/likip/cbclongrangevisuals/server/` — сбор состояния и отбор наблюдателей.
- `src/main/java/dev/likip/cbclongrangevisuals/network/` — ограниченный протокол и освещение.
- `src/main/java/dev/likip/cbclongrangevisuals/mixin/` — наблюдение за попаданиями и осколками CBC.
- `src/main/templates/META-INF/neoforge.mods.toml` — метаданные и обязательные зависимости.
- `docs/rendering-plan.md` — устройство рендера и оставшиеся проверки.
